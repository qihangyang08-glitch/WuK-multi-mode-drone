## 项目简介 (Project Overview)

WuK Multi-mode Drone 是一款 跨介质可变构无人机，能够在 空中 / 水面 / 地面 三种环境下切换形态并运动。
项目的目标是通过 单一遥控器 控制，实现飞行模式与地面车辆、水上航行的自然转换。

本项目的特点：

跨介质运动：支持飞行、地面行驶与水上漂浮。

结构变构：电机臂可旋转，既可作为螺旋桨支撑，也能变为车轮；起落架可收放。

多控制板协同：飞控（ArduPilot）与 Arduino 控制板协同工作，实现动力与结构的耦合控制。

通道复用：利用接收机的 SBUS + PWM 双输出，减少通道占用，让单个遥控器即可完成模式切换与姿态控制。

可扩展性：通过参数化设计，舵机角度、电推杆时长、起落架等待时间都可调节，方便后续实机调试与优化。

模式联动（同一个遥控器开关同时触发飞控与 Arduino 的模式切换）。

结构与动力耦合（结构变化与飞控控制逻辑配合，确保在模式切换过程中平稳过渡）。

## 硬件组成 (Hardware Components)

本项目主要由 控制系统 和 变形系统 两部分构成。

1. 控制系统

飞控 (Flight Controller)：微空 H743 V2

基于 ArduPilot 固件，支持 Lua 脚本扩展。

负责四旋翼飞行控制（姿态、导航、传感器融合）。

提供电机控制信号输出，并能在脚本覆盖时切换地面/水面模式逻辑。

Arduino 控制板：Mega2560

接收接收机的 PWM 信号，负责控制舵机、电推杆与起落架。

与飞控共享通道 7，实现模式切换时的联动。

通过参数化设计，舵机角度、电推杆时长、起落架等待时间均可调整，便于实机调试。

接收机 (Receiver)

10 通道，支持 SBUS 与 PWM 双输出。

SBUS 输出给飞控，用于常规飞行控制。

PWM 输出 7–10 通道给 Arduino，用于模式切换与变形控制。

遥控器 (Transmitter)

通过接收机与飞控/Arduino 交互，统一控制飞行模式与结构变形。

2. 变形系统

电机 (Motors)：EX2809 无刷电机 × 4

在飞行模式下作为四旋翼动力系统。

在地面/水面模式下，通过电机臂旋转和推力方向切换，作为车轮推进或水平推力来源。

电机臂舵机 (Servo Motors)

控制电机臂的角度，实现电机朝向“向下推力”与“向后推力”的切换。

电机臂旋转后可充当轮子支撑或水面推进桨。

电推杆 (Linear Actuator)

负责改变机体宽度（收缩/伸展）。

确保电机臂旋转时，轮子不会刮地面或机体。

起落架 (Landing Gear)

可收放式起落架，替代早期设计中的气囊。

在空-陆切换时支撑机体，保证安全着陆与离地高度。

## 通道分配 (Channel Mapping)

说明：接收机通过 SBUS → 飞控 (微空 H743 V2)，并通过 PWM（7–10 通道）→ Arduino Mega2560 给变形控制板送开关/命令信号。务必保证飞控与 Arduino 对同一通道的语义一致（例如 CH7 的三态范围在 Arduino 与 Lua 两端必须相同）。

1) 总体分配（推荐）
通道	使用对象	功能说明
CH1–CH4	飞控 (H743V2)	姿态/飞行控制（必保留，不可被 Arduino 占用）
CH5	飞控	定高/定点开关（保留给飞控）
CH6	飞控	电机解锁 / 致动（建议给飞控，若通道故障需维修或重映射）
CH7	飞控 & Arduino	模式切换（按信号值|三态）：低 = 飞行， 中 = 水面， 高 = 地面
CH8	Arduino	电推杆（手动/三态控制：伸/停/缩）
CH9	Arduino	预留（备用）
CH10	Arduino	模式锁定（高=锁定，低=解锁）
2) CH7（三态）默认 PWM 阈值（请在 Arduino 与 Lua 两端统一）

飞行（Flight）：PWM ≤ 1200

水面（Water）：PWM ∈ [1300, 1700]

地面（Ground）：PWM ≥ 1800

说明：上面的阈值是当前代码中的默认值（可调）。调试时应在地面站/串口打印处观察实际读数并酌情调整阈值以避免处于边界抖动误判。

3) Arduino 输入/输出 引脚 映射（当前固件对应）
输入（PWM 信号）

pwmInput1 = 45 → CH10（模式锁定）

pwmInput2 = 2 → CH7（模式切换）

pwmInput3 = 3 → CH8（电推杆手动）

pwmInput4 = 13 → CH9（预留）

输出（舵机 / 控制）

servoPin1 = 11 → 摇臂舵机 1

servoPin2 = 10 → 摇臂舵机 2

servoPin3 = 4 → 电机臂舵机 A

servoPin4 = 5 → 电机臂舵机 B

servoPin5 = 6 → 电机方向舵机 C

servoPin6 = 7 → 电机方向舵机 D

servoPin7 = 8 → 电推杆 1

servoPin8 = 9 → 电推杆 2

servoPin9 = 12 → 起落架舵机（替代旧气泵）

注：以上是程序里默认的引脚映射。若 PCB / 分压板接线不同，请在 arduino/ 代码头部对照修改并记录在 docs 中。

4) 注意事项与调试建议

不要占用 CH1–CH4：这四通道是姿态控制，任何误用都会导致飞控行为不稳定或直接失控。

CH6 状况：系统说明里曾提到 CH6 有故障记录（若仍故障，请尽快维修或将解锁功能重映射到可用通道，并同步飞控参数）。

一致性：修改阈值或通道映射后，务必同时更新 Arduino 代码与 Lua 脚本 并做地面测试。

加滤波/防抖：模式切换（CH7）应做滤波或滑动平均，避免边界抖动造成误切换（当前 Arduino 已实现 5 样本滑动平均）。

调试手段：

在地面站（Mission Planner / QGroundControl）查看 RC 通道 PWM 值。

使用 Arduino 串口打印 Lock/Mode/signal 值验证接收到的 PWM。

起初调试时务必拆桨或断开电调，以免误动作造成危险。

保留 CH9 作为备用：如果后期需要增加功能（如摄像头云台、附加舵机），优先使用 CH9 或重新规划。

5) 建议的测试流程（每次改映射或阈值后都做）

在地面站观察并记录各通道在三种开关位置下的 PWM 实测值（取平均）。

根据实测结果微调 Arduino/Lua 中的阈值常量。

在不带桨的情况下，单步测试 Arduino：先手动用 CH8 控制电推杆，确认伸/缩正确。

测试 CH7 的三态切换：确认 Arduino 与 Lua 都检测到相同模式并打印状态。

最后在安全环境下带桨试飞/试地面行驶/试水面（分步验证）。

## 模式说明 (Modes)

无人机具备 三种工作模式，分别对应遥控器 CH7 三段开关：

低位 (≤1200 μs) → 飞行模式 (Flight)

中位 (1300–1700 μs) → 水面模式 (Water)

高位 (≥1800 μs) → 地面模式 (Ground)

飞控 (ArduPilot) 与 Arduino 控制板同时监听 CH7，保证动力控制与机构控制同步切换。

1. 飞行模式 (Flight Mode)

动力形式：四旋翼，电机朝下提供升力。

机构状态：

电机臂上摆，形成十字结构。

起落架收起，保证气动性能。

电推杆根据需求自由伸缩

应用场景：空中飞行、跨区域快速转场。

2. 水面模式 (Water Mode)

动力形式：电机臂下摆，电机推力方向调整为水平，提供前进与转向动力。

机构状态：

电推杆缩起、使四臂垂直。

起落架保持收起，不参与水面支撑。

依靠机体四角固定浮力罐提供浮力。

应用场景：水面航行、湖泊/河流过渡。

说明：水面模式是地面模式的简化版，不需要起落架动作，降低机构复杂性。

3. 地面模式 (Ground Mode)

动力形式：电机臂下摆后，桨叶充当车轮。电机推力方向转为水平，驱动车轮前进。

机构状态：

起落架放下，确保机体支撑。

电推杆伸长 → 机体变窄，避免轮子刮地。

电机臂下摆 → 轮子落地。

电推杆缩回 → 机体恢复高度，同时起落架收回，最终由轮子着地。

应用场景：地面移动、复杂地形过渡。

说明：该模式需要严格的切换顺序（起落架 → 推杆 → 电机臂 → 推杆 → 收起落架），否则会造成机械干涉。

模式切换流程总结

飞行 → 水面：只需下摆电机臂并切换电机方向。

飞行 → 地面：放下起落架 → 推杆伸长 → 电机臂下摆+方向调整 → 推杆缩回 → 收起落架。

地面 → 飞行：反向操作：推杆缩回 → 放下起落架 → 推杆伸长 → 电机臂上摆+方向恢复 → 收起落架。

注意事项

模式切换时需保证 CH10（模式锁定）=解锁，否则 Arduino 不会执行动作。

起落架与推杆的动作时间通过参数化延时控制，可根据实机调试调整。

建议飞行员在空旷环境下进行模式切换，避免因动作延时或干涉导致失控。

5) 遥控器操作指南
   5.1 基础操作流程

上电初始化: Arduino启动后自动进入飞行模式
锁定状态确认: 系统默认锁定，CH10通道应在低位

步骤2: 模式切换
- CH7低位: 切换到飞行模式
- CH7高位: 切换到陆/水模式
- 观察舵机动作完成情况
   5.2 各功能详细操作
      5.2.1 起落架控制（CH9）
收起起落架: CH9 < 1100μs
放下起落架: CH9 > 1900μs
保持当前状态: 1100μs < CH9 < 1900μs
      5.2.2 推杆控制（CH8）
推杆伸出: CH8 > 1900μs
推杆缩回: CH8 < 1100μs  
推杆停止: 1100μs < CH8 < 1900μs
      5.2.3 模式切换观察要点
飞行 → 陆/水模式:

观察电机臂从上转到下（servo0: 130°→20°）
观察推力方向从下转到水平（servo1: 45°→155°）
整个过程约2秒完成

陆/水 → 飞行模式:

观察电机臂从下转到上（servo0: 20°→130°）
观察推力方向从水平转到下（servo1: 155°→45°）

   5.3 安全操作注意事项

必须先解锁: 所有操作前确保CH10在高位
避免频繁切换: 模式切换有2秒延时，避免快速重复操作
观察动作完成: 等待舵机完全到位再进行下一步操作
紧急锁定: 任何时候可通过CH10低位紧急锁定系统

### Lua 脚本 
1) 目的
  - 在 ArduPilot 飞控上以 Lua 脚本形式运行，和飞控参数/输出集成，实现相似的三模式行为（Flight/Water/Ground），并在非飞行模式下将电机输出由脚本接管以实现地面/水面驱动逻辑。
  - 脚本文件：`/lua/v1.8.lua`，需放置在飞控 SD 卡 `/scripts/` 目录下。

2) 主要功能要点
  - 定义了遥控通道映射（CH_THROTTLE、CH_ROLL、CH_PITCH、CH_YAW、CH_MODE）和用于脚本控制的输出函数编号（FN_MOTORx / FN_AP_MOTORx）。
  - 根据 CH_MODE 的 PWM 值区分三种模式（与 Arduino 代码保持一致的低/中/高 PWM 区间判断）。
  - 在非飞行模式（Ground/Water）时，脚本会通过 `SRV_Channels:set_output_pwm` 或 `param:set('SERVO%d_FUNCTION', ...)` 将指定舵机/输出函数切换为脚本控制，继而调用 `set_motor_pwm` 输出速度/转向补偿。
  - Ground/Water 模式下实现基于油门/滚转（用于转向）与姿态（Lua 脚本会读取 AHRS 的俯仰角）进行不同的转向/功率分配逻辑。
  - 通过 `init()` 启动并返回 `update` 回调（周期性运行，默认 50 ms），在 `update` 中检测模式变化并调用对应处理函数。

3) 集成与安全
  - 当切换到 Flight 模式，脚本尝试恢复电机控制权给 ArduPilot（通过设置 SERVO*_FUNCTION 到 AP 的 Motor 函数），提高安全性。
  - 在使用前请在仿真或地面台架上充分验证逻辑，确保脚本不会在未解锁或姿态不稳定时驱动电机。

4) 脚本结构
- 初始化 (init)：检查 API 可用性，设置 SERVO 功能号。  
- 模式检测 (get_current_mode)：根据 CH7 PWM 判定当前模式。  
- 模式切换 (on_mode_change)：在模式变化时，自动接管或释放电机控制权。  
- 控制逻辑：
  - `handle_flight_mode()`：归还飞控电机控制。  
  - `handle_water_mode()`：水面运动控制，带油门映射参数化。  
  - `handle_ground_mode()`：地面运动控制，模拟差速转向。  
- 调试工具：`debug_channels()`、`debug_servo_functions()`、`debug_system_status()`。  


5) 注意
  - Lua 脚本与飞控参数/舵机函数编号强耦合，部署前务必核对目标飞控上的 `SERVOx_FUNCTION` 与脚本中的编号一致。
  - 使用 `gcs:send_text` 可在地面站查看调试与状态消息。

6) 使用方法
1. 将 `v1.6.lua` 放入飞控 SD 卡 `/scripts/`。  
2. 在 Mission Planner / QGC 查看 GCS 信息，确认 `LUA_INFO: 初始化完成`。  
3. 使用 CH7 三段开关测试模式切换，观察日志输出确认判定是否正确。  
4. 调整水面模式油门参数以获得理想推进响应。

## 使用说明 (Usage)
1. 准备工作

硬件检查

确认螺旋桨、电机、舵机、电推杆和起落架连接正确。

检查接收机是否稳固安装，并能同时输出 SBUS（飞控）与 PWM（Arduino）。

确认电源接线安全，避免短路。

飞控准备

将飞控固件更新至支持 Lua 脚本的 ArduPilot 版本。

将 v1.6.lua 脚本复制到飞控 SD 卡的 /scripts/ 目录下。

通过地面站（Mission Planner/QGroundControl）检查飞控能正确识别各通道输入。

Arduino 准备

使用 Arduino IDE 打开 arduino/arduino.ino。

选择 Arduino Mega2560 作为开发板型号，上传程序。

打开串口监视器（9600 波特率），确认能打印接收到的通道状态。

安全措施

调试前务必 拆下螺旋桨 或断开电调信号线。

模式切换测试时，应避免人员站在无人机正前方或下方。

2. 上电与初始化

打开遥控器，确保各通道处于安全状态：

模式切换开关（CH7）置于 飞行模式 (低位)。

模式锁定（CH10）置于 锁定状态，防止误触发。

接通无人机电源，等待飞控与 Arduino 初始化完成：

飞控 LED 正常闪烁。

Arduino 舵机自动归位到初始角度（写在程序的 setup() 阶段）。

解锁模式（CH10 低位）后，Arduino 才会响应模式切换信号。

3. 模式切换操作

飞行模式 (CH7 低位 ≤1200)

电机臂上摆，推力方向向下。

起落架收起，电推杆缩回。

用于常规飞行。

水面模式 (CH7 中位 1300–1700)

电机臂下摆，推力方向转为水平。

起落架保持收起，依靠浮力罐漂浮。

适合水面航行。

地面模式 (CH7 高位 ≥1800)

按照预设顺序：起落架放下 → 电推杆伸长 → 电机臂下摆 → 推力方向转向 → 电推杆缩回 → 收起落架。

最终由轮子着地，可进行地面行驶。

手动控制电推杆 (CH8)

高位：电推杆伸长。

低位：电推杆缩回。

中位：保持不动。

模式锁定 (CH10)

高位：锁定，禁止模式切换。

低位：解锁，可切换模式。

4. 地面调试流程（推荐）

将 CH10 置于 解锁，在拆桨状态下逐个测试：

切换 CH7 三段，观察串口输出的模式值是否与遥控器一致。

检查舵机与推杆动作是否符合预期。

在 Mission Planner 中确认 Lua 脚本输出的模式状态与 Arduino 相符。

若发现动作不一致，应检查：

遥控器通道顺序是否正确。

Arduino/Lua 程序中的 PWM 阈值是否与实测值匹配。

舵机安装位置是否对应正确。

5. 注意事项

起落架动作需要数秒，切换模式时需提前操作，避免结构未完成动作即强行进入另一模式。

初次试飞/试跑请在空旷场地进行，最好有保护措施。

所有模式切换建议先在地面模拟，确认动作流程正确后再在空中/水面执行。

## 参数调整 (Tuning)

无人机的电控程序支持部分 参数化设置，通过修改代码中的常量即可调整舵机角度、电推杆时长、起落架等待时间和模式阈值。

调参建议：

初次调试使用 默认值，避免机械干涉或电机超载。

修改后务必进行 地面测试（无桨），确认动作顺序与幅度正确，再进行实飞/实地测试。

1. Arduino 程序参数
参数名	作用	默认值	推荐范围	调整说明
servoDelay	控制电机臂/方向舵机在动作过程中的单步延时，影响舵机转速。	50 ms	20–100 ms	数值越大，舵机转动越慢，动作更平稳但切换耗时更长。
