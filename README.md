## 1. 项目简介 (Project Overview)

WuK (Wuhan University Kopter) 是一款基于 ArduPilot 的跨介质可变构四旋翼无人机项目。该项目旨在实现四旋翼在飞行模式与地面模式（车辆形态）之间的动态无缝切换。

通过单一遥控器控制，无人机可以通过变形机构（电机臂旋转、电推杆伸缩）改变运作形态。同时，飞控底层的混控算法对变形过程中的推力矢量进行实时动态补偿，确保变构过程中的高度保持与姿态稳定。

**核心本版特性差异（相比早期规划）：**
- 舍弃了易受干扰的 PWM 并行通道下发给从机的方式，改为**稳定的 UART 串口通信（单向）**驱动。
- 舍弃了 Lua 脚本实现的控制权接管，改为**直接在 ArduPilot 底层 C++ 源码中开发独立的飞行模式**（`mode_morph`, `mode_ground`），并深度修改了 AP_Motors 的推力混控与补偿算法。
- 引入了完整的 SITL 软件在环仿真和系统级数据分析工具。

## 2. 系统架构 (System Architecture)

整个控制系统采用**双控协同**架构，由飞控（ArduPilot）与从控板（Arduino）构成主从关系：

- **主飞控 (ArduPilot)**
  - 负责核心姿态解算、状态机管理、导航以及旋翼电机驱动。
  - 包含三种自定义变构模式控制逻辑。
  - 计算变构过程中的推力补偿，并通过 UART 将变构指令下发给 Arduino。
- **执行从控 (Arduino Mega2560)**
  - 仅作为“执行器驱动系统”。
  - 监听飞控发来的串口指令报文。
  - 精确控制电机臂舵机（实现推力方向 0°~90° 旋转）和电推杆（实现机身轮距的展收）。
- **接收机 (Receiver)**
  - 采用 SBUS 协议直接连接飞控。遥控器的所有通道数据全部由飞控统一接收、解析后再由飞控的逻辑决断后下发动作给从控，避免了双头接收导致的状态不同步。

## 3. 硬件组成 (Hardware Components)

1. **控制核心**
   - **飞控**：兼容 ArduPilot 固件的高性能飞控（如微空 H743 V2）。
   - **从控板**：Arduino Mega 2560，用于驱动多路舵机与电平设备。
2. **动力系统 (飞行/地面复用)**
   - **电机**：EX2809 无刷电机 × 4，在 X 型布局下提供升力，并在地面模式下作为差速驱动车提供动力。
3. **变构执行系统 (由 Arduino 控制)**
   - **机臂舵机**：控制电机臂上下摆动，改变推力矢量方向（0°为向下，90°为向后）。
   - **电推杆 (Linear Actuator)**：改变机体宽度（伸展或收缩），用于在地面模式下为底部气囊提供足够的离地间隙，防刮蹭，还可动态调节飞行性能。

## 4. 通道分配 (Channel Mapping)

在当前架构下，遥控通道配置如下：

| 功能模块 | 遥控器开关 | 通道 | 状态与对应动作 |
| :--- | :--- | :--- | :--- |
| **基础飞行** | 摇杆 | CH1-CH4 | Roll、Pitch、Throttle、Yaw 控制（由飞控直接按需使用） |
| **形态切换 (硬件动作)** | SWD | CH7 | 下位(1000): 触发地面展开序列<br>上位(2000): 触发飞行收拢序列 |
| **电推杆手动** | SWE | CH8 | 上位(2000): 推杆伸展<br>中位(1500): 停止<br>下位(1000): 推杆收缩 |
| **飞行/地面控制模式** | SWA | CH9 | 上位(1000): 飞行控制逻辑<br>下位(2000): 地面行驶控制逻辑 / 变构阶段使能 |

*初始建议上电归位状态：SWA:上 | SWE:中间 | SWD:上*

## 5. 模式说明 (Modes)

WuK 项目在 ArduPilot 中新引入或重度适配了三个核心运行模式：

1. **LOITER 模式 (常规悬停)**
   - **机构状态**：标准四旋翼，电机完全朝下 (0°)。推杆缩回。
   - **动力表现**：姿态控制由标准旋翼 PID 接管。

2. **MORPH 模式 (变构过渡)**
   - **机构状态**：电机倾角在 0°→45°（或其他安全大角度）之间切换的动态过程。
   - **动力表现**：在变构过程中，水平推力分力会随着倾角增大而抵消，系统**底层在此模式中自动引入推力补偿矩阵**（垂直推力 $T_z = T / \cos\theta$）。确保在变构过程中高度保持稳定（±0.5m 内）。

3. **GROUND 模式 (地面行驶)**
   - **机构状态**：电机倾角转为水平向后 (90°)。机体通过推杆伸展，螺旋桨充当车轮着地。
   - **动力表现**：此时 `output_armed_stabilizing` 混控被旁路，电机推力直接映射控制。支持类似 RC 车的**差速转向**：俯仰杆(Pitch) 控制前进/后退推力，横滚杆(Roll) 控制左右转向的差速输出。

## 6. 软件设计 (Software Design)

### 6.1 ArduCopter 侧 (飞控端)
底层进行了深度二次开发（无需外挂脚本）：
- **Mode 模块**：增加了 `mode_morph.cpp` (变构高度保持和过渡逻辑) 和 `mode_ground.cpp` (地面差速推测控制并避开传统积分器饱和问题)。
- **混控器重写**：修改 `libraries/AP_Motors/AP_MotorsMatrix.cpp`，支持动态更新电机方向矩阵，在输出端加入了姿态倾角增益补偿计算和高度补偿计算。
- **SITL 仿真**：修改 `SIM_Frame.cpp` 等支持带有伺服延迟与几何推力矢量的物理模型仿真，支持输出专用频度的 `wuk_gb.jsonl` 日志。

### 6.2 Arduino 侧 (从机端)
固件(`main.cpp`)维护一个独立的状态机来执行平滑的机械转场：
- **TRANSITION_TO_GROUND (0°→90°)**: 平滑倾转机臂(30°/s) → 倾转电机(30°/s) → 锁定至 GROUND。
- **TRANSITION_TO_FLIGHT (90°→0°)**: 慢速回收到45°防刮蹭(10°/s) → 加速回正机臂(30°/s) → 回正电机(30°/s) → 锁定至 FLIGHT。

## 7. 串口通信协议 (UART Protocol)

飞控与 Arduino 采用**单工通信 (Simplex)**，飞控 TX 连 Arduino RX3，波特率 `9600`（参数 `WUK_BAUD`）。这避免了 3.3V 与 5V 的逻辑电平冲突风险。

**帧结构（小端序）：**
| 0xAA | MsgID | Len | Payload[0..N] | CRC8 |

**通讯指令：**
- `0x01 (CMD_ARM_SERVO)`：Payload=`uint16_t` 角度。控制强制舵机角度。
- `0x02 (CMD_ACT1)`：Payload=`uint16_t` PWM值。处理形态切换序列(1000为地，2000为天)。
- `0x03 (CMD_ACT2)`：Payload=`uint16_t` PWM值。处理电推杆伸缩。
- `0x04 (CMD_STATUS_REQ)`：心跳包， Arduino 接收后重置超时时间。

## 8. 使用说明与调试 (Usage & Tuning)

1. **准备工作**
   - 首次烧录 Arduino 固件，并确保串口与飞控 Telem/Serial 端口正常连接（波特率 9600，协议不限制为 Mavlink），且从机独立供电满足大电流需求。
   - 打开遥控，并确保起步处于全归位安全状态 (见[通道分配](#4-通道分配-channel-mapping))。

2. **验证通讯与舵机逻辑（地面静态）**
   - 在串口监视器中观察 Arduino 固件发回的日记信息（如 `[LIVE] | RX: MODE_SWITCH(2000)`）。
   - 切按 SWD，观察机臂以及电机的平稳转场序列是否顺畅（未有互相干涉）。

3. **参数配置说明**
   - 变构阶段高度如出现缓慢掉落，可通过调控飞控参数适当放大基础油门补偿系数。
   - `arduino/main.cpp` 中可根据实际安装连杆微调舵机的逻辑角度映射。

## 9. 数据分析工具 (Data Analysis Tools)

项目自带完整的飞行数据与变构分析闭环生态：
- **`wuk_analyzer` (C++)**: 用于快速解析 SITL `wuk_gb.jsonl`，检测下降率并打时间戳标记事件，输出为 `.csv` 格式序列。
- **`wuk_plotter.py` (Python)**: 消费上述的 CSV 文件，自动绘制 4 张诊断大图：
  1. 电机推力防线与机体 Roll 轴倾角
  2. 电机推力在世界坐标系投影
  3. 各电机推力曲线与垂直分量消耗状态
  4. 机体绝对高度与变构坠落事件侦测（含 5m 高度守卫线）

## 10. 未来改进 (Future Work)

1. **硬件联调强化**：推进真机实际飞行验证，测试变形机构的机械稳定性以及长臂下的抗震能力。
2. **电流与电量反馈**：实现双向串口通信机制，利用 5V-3.3V 电平转换器安全允许 Arduino 反馈执行状态与错误告警回飞控日志系统。
3. **硬件整合**：计划未来将双控集成为单控。
