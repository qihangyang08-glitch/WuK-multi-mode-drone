## 1. 系统概述

### 1.1 系统定位
本 Arduino 程序为跨介质可变构无人机的机械变形控制模块，负责机体的机械变形动作。与飞控系统（ArduPilot）协同工作，实现无人机在三种工作模式之间的切换：飞行（Flight）、地面（Ground）与水面（Water）。

代码分为两部分：用于微控制器（Arduino / PlatformIO）的 `src/main.cpp`，以及运行在 ArduPilot 的 Lua 脚本（见仓库 `LUA/` 目录），分别用于不同硬件/平台的控制实现与集成。

### 1.2 核心功能
- 模式切换：飞行模式 ↔ 陆/水模式
- 起落架控制：收放起落架支持地面操作
- 推杆控制：调节机体宽度（手动/串口控制）
- 舵机控制：电机臂方向与推力方向切换
- 双控制源：支持遥控器 PWM 信号和串口命令控制

## 2. 设计架构

### 2.1 硬件架构（示意）

```
遥控器接收机 ──PWM信号──┐
                     ├──→ Arduino Mega2560 ──→ 执行机构
串口命令 ──────────────┘                    ├── 舵机×6 (电机臂/方向/辅助)
                                          ├── 电推杆×2
                                          └── 起落架舵机×1
```

### 2.3 状态机设计（简述）

系统通过状态机管理模式切换与控制权：

```
系统模式： FLIGHT_MODE <--> SURFACE_MODE（通过解锁 + 模式切换触发）

控制权： SIGNAL_CT（遥控） <--> SERIAL_CT（串口），通过 ct_open/ct_close 切换
```

## 3. 关键设计特性

### 3.1 信号滤波系统

设计目的：防止遥控信号抖动引发误动作。

实现方式（示例）：5 点移动平均滤波器。

```cpp
template<size_t N>
class MovingAverageFilter {
  // 5点移动平均滤波（示例）
};
```

要点：每通道独立滤波，滤波结果用于状态判断与阈值比较。

### 3.2 渐进式模式切换

设计思想：模式切换以分步骤方式平滑执行，避免机械冲击。

```cpp
// 飞行 -> 陆/水 模式切换示例
void transitionToSurfaceMode() {
  static uint8_t transitionStep = 0;
  // 分若干步完成舵机动作，每步延迟以保证平滑
}
```

优势：减少机械磨损，便于观察与中断处理。

### 3.3 安全锁定机制

多层安全：硬件锁（遥控器通道）、软件权限检查、以及舵机写入限制。

```cpp
// 硬件安全锁示例
if (filteredValues[0] < 1100) {
  SystemStatus.STATE_LOCKED = true;
}

// 舵机安全写入（示例）
void safeServoWrite(uint8_t servoIndex, int value) {
  value = constrain(value, 0, 180);
  if (servoIndex < 9 && servos[servoIndex].attached()) {
    servos[servoIndex].write(value);
  }
}
```

## 4. 通道配置与信号映射

### 4.1 输入通道（遥控器 PWM）

| 通道 | 引脚 | 功能 | 信号范围 | 备注 |
|------|------|------|----------|------|
| CH7  | D2   | 模式切换 | 1000-2000 μs | 低值→飞行，高值→陆/水 |
| CH8  | D3   | 推杆控制 | 1000-2000 μs | 低值→缩回，高值→伸出 |
| CH9  | D13  | 起落架控制 | 1000-2000 μs | 低值→收起，高值→放下 |
| CH10 | D45  | 系统锁定 | 1000-2000 μs | 低值→锁定，高值→解锁 |

### 4.2 输出控制（舵机 / 推杆）

| 舵机    | 引脚   | 功能     | 角度/脉宽范围 | 说明 |
|---------|--------|----------|---------------|------|
| Servo0  | D11    | 电机臂   | 20°-130°      | 控制电机朝向（上/下） |
| Servo1  | D10    | 推力方向 | 45°-155°      | 控制推力方向（下/水平） |
| Servo2-5| D4-D7  | 辅助舵机 | 0°-180°       | 微调用途 |
| Servo6-7| D8-D9  | 电推杆   | 1000-2000 μs  | PWM 控制推杆伸缩 |
| Servo8  | D12    | 起落架   | 1000-2000 μs  | PWM 控制起落架收放 |

## 5. 遥控器操作指南

### 5.1 基础操作流程

#### 5.1.1 系统启动检查
1. 上电初始化：Arduino 启动后默认进入飞行模式
2. 锁定状态确认：系统默认锁定，CH10 通道应在低位
3. 串口连接：波特率 9600，观察初始化信息

#### 5.1.2 解锁与模式切换

步骤 1 — 解锁系统：
- 将 CH10（锁定通道）拨到高位
- 串口显示："UNLOCKED"

步骤 2 — 模式切换：
- CH7 低位：切换到飞行模式
- CH7 高位：切换到陆/水模式
- 观察舵机动作完成情况

### 5.2 各功能操作说明

#### 5.2.1 起落架控制（CH9）

```
收起起落架: CH9 < 1100 μs
放下起落架: CH9 > 1900 μs
保持当前状态: 1100 μs < CH9 < 1900 μs
```

#### 5.2.2 推杆控制（CH8）

```
推杆伸出: CH8 > 1900 μs
推杆缩回: CH8 < 1100 μs
推杆停止: 1100 μs < CH8 < 1900 μs
```

#### 5.2.3 模式切换观察要点

飞行 → 陆/水：
- 观察电机臂从上转到下（servo0: 130° → 20°）
- 观察推力方向从下转到水平（servo1: 45° → 155°）
- 整体过程约 2 秒

陆/水 → 飞行：
- 电机臂从下转到上（servo0: 20° → 130°）
- 推力方向从水平转到下（servo1: 155° → 45°）

### 5.3 安全注意事项
1. 必须先解锁：所有操作前确保 CH10 在高位
2. 避免频繁切换：模式切换有延迟（约 2 秒），避免快速重复操作
3. 观察动作完成：等待舵机完全到位再进行下一步操作
4. 紧急锁定：任何时候可通过 CH10 低位紧急锁定系统

## 6. 串口命令操作指南

### 6.1 串口连接设置

```
波特率: 9600
数据位: 8
停止位: 1
校验位: 无
换行符: \n
```

### 6.2 基本命令集

控制权管理：

```
ct_open   - 切换到串口控制模式
ct_close  - 切换到遥控器控制模式
```

系统锁定控制：

```
lock      - 锁定系统（安全模式）
unlock    - 解锁系统（允许操作）
```

模式切换命令：

```
mdchg     - 模式切换（飞行 ↔ 陆/水）
```

硬件控制：

```
gearup    - 收起起落架
geardown  - 放下起落架

armex     - 推杆伸出
armre     - 推杆缩回
armst     - 推杆停止
```

示例：

```
> ct_open
[OK] Serial control enabled
> unlock
[OK] System unlocked
> geardown
[OK] Landing gear extended
```

### 6.3 典型串口操作序列（示例）

1. 获取控制权：ct_open
2. 解锁系统：unlock
3. 放下起落架（地面操作准备）：geardown
4. 切换到陆地模式：mdchg
5. 手动控制推杆（可选）：armex / armst
6. 切换回飞行模式：mdchg
7. 收起起落架：gearup
8. 交还控制权：ct_close

调试输出（示例）：

```
==== System Status ====
Controller: SERIAL
UNLOCKED
Mode: SURFACE
Arm State: STOPPED
Landing Gear: EXTENDED
Filtered Values: 1500 1800 1200 1900
=======================
```

### 6.4 错误处理

常见错误与解决：

```
[ERROR] Unknown command: xxx      -> 检查命令拼写
[ERROR] System is locked           -> 先执行 unlock
[WARN] Transition already in progress -> 等待当前切换完成
```

故障排除步骤（建议）：
1. 检查串口连接与波特率
2. 确认 Arduino 供电正常
3. 检查舵机电源与连接
4. 使用基础命令测试系统响应
5. 观察调试输出定位问题

## 9. 总结

本 Arduino 控制程序采用模块化与状态机设计，结合双控制源（遥控器 + 串口）、信号滤波与安全锁定等机制，保证了跨介质模式切换的可靠性与可维护性。

主要优势：
- 多层安全保护
- 灵活的控制模式
- 完善的状态反馈与调试能力
- 易于维护与扩展

该系统已在实际项目中验证，能够稳定完成无人机跨介质模式切换任务。
