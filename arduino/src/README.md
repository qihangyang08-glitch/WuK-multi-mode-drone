-  该目录为arduino变形系统的源码，包含两个版本：main.cpp和pre_debug_version.cpp。

-  这是两个并行版本，烧录时选择需要的版本即可。

-  “for—test”分支中的程序都是测试时的程序，重在调试功能。目前主要工作也都围绕该版本展开。

-  main.cpp是硬件测试时所用版本。这里所指的硬件测试是指上电让arduino控制舵机测试舵机也没有被正确驱动，以及运动的状态和时机是否正确。

-  pre_debug_version.cpp则是可以用在硬件测试前的预测试的版本，其加强了调试内容的精细度和即时性，相应地降低了性能，主要用在测试遥控器到达arduino控制板的信号是否完整、顺序是否正确；arduino程序是否正确地处理和应对这些信号以及是否产生正确的输出信号。这些测试都能在不上电的情况下完成。

-  但其也有局限性，即无法确认程序中的引脚映射是否和实际的pcb/分压版接线顺序一致。
