# WuK 项目 - Arduino 从机固件

> **平台：** Arduino Mega 2560  
> **角色：** 通过 UART 接收来自 ArduPilot 飞控的指令并驱动执行器  
> **通信模式：** 单工 (Simplex)，仅接收飞控指令，不回传（避免 5V/3.3V 电平冲突）

---

## 一、整体架构

```
main.cpp
├── 硬件配置（引脚定义 + 舵机对象）
├── 通信协议（Serial3 接收飞控报文）
├── 状态机（5种模式 + 平滑过渡逻辑）
├── 报文解析器（状态机驱动的 UART 解析）
├── 指令处理函数（4条指令分发）
├── 舵机映射输出（逻辑角度→实际角度）
└── 调试日志输出（固定格式字段化输出）
```

---

## 二、报文协议格式

```
| 0xAA | MSG_ID | LEN | PAYLOAD[0..N] | CRC8 |
```

| 字段 | 说明 |
|---|---|
| `0xAA` | 帧头，固定值 |
| `MSG_ID` | 指令 ID（1字节） |
| `LEN` | Payload 长度（≤16字节） |
| `PAYLOAD` | 数据体，通常为 2字节 uint16（小端序） |
| `CRC8` | CRC8-Maxim，覆盖 MSG_ID+LEN+PAYLOAD |

**串口配置：** `Serial3`（RX: Pin 15），波特率 `9600`，需与 ArduPilot 中 `WUK_BAUD` 参数一致。

## 三、报文 → 内容 → 动作 → 模式 → 调试输出

### 0x01 `CMD_ARM_SERVO` — 手动机臂控制

| 项目 | 内容 |
|---|---|
| **Payload** | `uint16` 目标角度（0~90 度） |
| **触发动作** | 立即将机臂舵机设定到目标角度，电机强制归零（0°） |
| **切换模式** | → `MODE_MANUAL_SERVO` |
| **舵机映射** | `armServos[0]`：0°→20°，90°→130°<br>`armServos[1]`：0°→155°，90°→45°<br>`motorServos[0,1]`：强制写 0°<br>`motorServos[2,3]`：强制写 170° |
| **调试输出示例** | `[LIVE]  \| RX: ARM_SERVO(45) \| MANUAL A:45 M:0` |

---

### 0x02 `CMD_ACT1` — 模式切换序列

| Payload 值 | 触发动作 | 切换模式 |
|---|---|---|
| `> 1800` | 启动地面展开序列 | → `TRANSITION_TO_GROUND` |
| `< 1200` | 启动飞行收拢序列 | → `TRANSITION_TO_FLIGHT` |
| `1200~1800` | 无响应 | 不变 |

**`TRANSITION_TO_GROUND` 序列（0° → 90°）：**
1. 机臂 0°→90°，速度 30°/s
2. 机臂到位后，电机 0°→90°，速度 30°/s
3. 完成后锁定为 → `MODE_GROUND`

**`TRANSITION_TO_FLIGHT` 序列（90° → 0°）：**
1. 机臂 90°→45°，速度慢 10°/s（慢速保护阶段）
2. 机臂 45°→0°，速度 30°/s
3. 机臂到位后，电机 90°→0°，速度 30°/s
4. 完成后锁定为 → `MODE_FLIGHT`

**调试输出示例：**
```
[LIVE]  | RX: MODE_SWITCH(2000) |  > GND A:23 M:0
[LIVE]  | Last: MODE_SWITCH(2000) | GROUND A:90 M:90
```

---

### 0x03 `CMD_ACT2` — 推杆控制

| Payload 值 | 触发动作 | 引脚输出 |
|---|---|---|
| `> 1800` | 推杆伸张 | `armActuators[0,1]` → 2000μs |
| `< 1200` | 推杆收缩 | `armActuators[0,1]` → 1000μs |
| `1200~1800` | 推杆停止 | `armActuators[0,1]` → 1500μs |

**调试输出示例：**
```
[LIVE]  | RX: PUSHROD(2000) | FLIGHT A:0 M:0
```

---

### 0x04 `CMD_STATUS_REQ` — 心跳/状态请求

| 项目 | 内容 |
|---|---|
| **Payload** | 无 |
| **触发动作** | `send_debug_status()` 当前为空函数，不执行任何操作 |
| **特殊处理** | 此报文**不更新** `lastCmdName`，不调用 `printLog`（心跳不刷屏） |

## 四、调试输出格式

每条输出格式固定为三字段：

```
[状态]  | RX/Last: 指令名(值) | 模式 A:机臂角度 M:电机角度
======================================
```

### 字段1 — 连接状态

| 输出 | 触发条件 |
|---|---|
| `[LIVE]` | 2秒内收到过有效报文，且无 CRC 错误 |
| `[ERROR]` | 最近有 CRC 校验失败或包长度非法（打印一次后清除） |
| `[LOST]` | 超过 2000ms 未收到有效报文 |

### 字段3 — 模式标识

| 输出 | 对应模式 |
|---|---|
| `MANUAL` | `MODE_MANUAL_SERVO` |
| `FLIGHT` | `MODE_FLIGHT` |
| `GROUND` | `MODE_GROUND` |
| ` > GND` | `TRANSITION_TO_GROUND` |
| ` > FLY` | `TRANSITION_TO_FLIGHT` |

### 特殊警告

当收到超过 100 字节但始终无法解析到有效帧时，每 10 秒最多输出一次警告，提示检查波特率 / 协议头 / MAVLink 配置。
