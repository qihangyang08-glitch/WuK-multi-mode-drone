# WuK变构四旋翼项目 - 项目介绍与进展

**更新时间**: 2025年12月11日  
**项目状态**: 核心功能已完成，SITL调试阶段

---

## 📋 项目概述

WuK (Wuhan University Kopter) 是一个基于ArduPilot的变构四旋翼无人机项目，实现了四旋翼在飞行模式和地面模式之间的动态切换。

### 核心特性

1. **三种工作模式**
   - **LOITER模式**: 标准四旋翼悬停，电机0°垂直朝下
   - **MORPH模式**: 0°→45°渐变过程，保持高度控制
   - **GROUND模式**: 90°水平构型，RC车式差速转向

2. **电机布局**
   - 标准X型布局：M1前右(45°), M2前左(-45°), M3后左(-135°), M4后右(135°)
   - 伺服驱动倾转：通过RC9通道控制0-90°倾转角度

3. **推力补偿机制**
   - Roll/Yaw因子旋转矩阵补偿（电机倾转后方向变化）
   - 垂直推力补偿：throttle /= cos(angle) 保持高度

4. **地面差速控制**
   - 俯仰杆(Pitch) → 前进/后退
   - 横滚杆(Roll) → 左右转向（差速推力）

## 🎯 最新进展 (2025-12-18)

### ✅ 已完成功能

1. **飞控核心逻辑**
   - **MORPH模式**: 基于LOITER的稳定变构（0°→45°），修复了高度保持和姿态控制。
   - **GROUND模式**: 实现了90°构型下的差速转向，修复了油门输出为0的问题（通过 `output_direct_to_motors` 旁路混控）。
   - **混控算法**: 
     - 实现了垂直和roll/yaw推力补偿 ($T_z = T / \cos\theta$)。
     
2. **SITL仿真环境**
   - **物理模型**: 实现了伺服倾转延迟和推力矢量旋转。
   - **参数调优**: 调整模型 (0.35)，解决了大角度倾转时的动力饱和坠落问题，验证了morph的运行情况仅与实际总推力大小有关。
   - **日志系统**: 实现了自定义 JSONL 格式的高频日志记录 (`wuk_gb.jsonl`)。

3. **数据分析工具链**
   - **wuk_analyzer (C++)**: 支持预启动数据过滤、平滑滤波、关键事件检测（变构开始、受控下降）。
   - **wuk_plotter (Python)**: 生成四合一分析图表，可视化电机倾角、推力变化及高度曲线。

### 🛠️ 关键修复记录

1. **Ground模式油门修复**: 重写 `ModeGround::output_to_motors`，绕过 `output_armed_stabilizing` 直接控制电机。
2. **Morph模式防坠落**: 
   - 参数层：降低SITL模型重量与悬停油门系数，增加推力余量。

## � 串口通信协议

飞控通过串口与Arduino执行机构通信，波特率由 `WUK_BAUD` 参数设定（默认 115200）。

### 帧结构
| 字节索引 | 内容 | 说明 |
| :--- | :--- | :--- |
| 0 | `0xAA` | 帧头 (Header) |
| 1 | `MsgID` | 消息ID |
| 2 | `Len` | 载荷长度 (N) |
| 3..3+N-1 | `Payload` | 数据载荷 (小端序) |
| 3+N | `CRC8` | 校验和 (从MsgID到Payload末尾) |

### 命令定义 (FC -> Arduino)

| MsgID | 宏定义 | 载荷 (Payload) | 说明 |
| :--- | :--- | :--- | :--- |
| `0x01` | `ARM_SERVO` | `uint16_t angle` | 设定机臂倾转角度 (0-90度) |
| `0x02` | `ACT1` | `uint16_t val` | 预留动作1 |
| `0x03` | `ACT2` | `uint16_t val` | 预留动作2 |
| `0x04` | `STATUS_REQ` | 无 | 状态查询心跳 (200ms周期) |

### 响应定义 (Arduino -> FC)

| MsgID | 宏定义 | 载荷 (Payload) | 说明 |
| :--- | :--- | :--- | :--- |
| `0x80` | `ACK` | `uint8_t cmd_id` | 收到命令确认 |
| `0x81` | `STATUS` | `uint16_t current_angle` | 当前实际角度反馈 |

### 代码实现
- **ArduCopter/WuK_Comms.h**: 协议类定义与常量
- **ArduCopter/WuK_Comms.cpp**: 协议打包与解析实现
