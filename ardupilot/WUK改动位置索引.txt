## 快速搜索命令

### 查找所有WuK改动
```bash
cd ~/ardupilot
grep -rn "\[WuK" ArduCopter/ libraries/ | grep -v "Binary"
```

### 按模块搜索
```bash
# MORPH模式相关
grep -rn "\[WuK-MORPH\]" ArduCopter/

# GROUND模式相关
grep -rn "\[WuK-GROUND\]" ArduCopter/

# 串口通信相关
grep -rn "\[WuK-Comms\]" ArduCopter/

# 电机混控相关
grep -rn "\[WuK\]" libraries/AP_Motors/

# SITL仿真相关
grep -rn "\[WuK-SITL\]" libraries/SITL/
```

### 查看特定文件的所有WuK改动
```bash
# 查看mode_morph.cpp的改动点
grep -n "\[WuK" ArduCopter/mode_morph.cpp

# 查看AP_MotorsMatrix.cpp的改动点
grep -n "\[WuK" libraries/AP_Motors/AP_MotorsMatrix.cpp
```
