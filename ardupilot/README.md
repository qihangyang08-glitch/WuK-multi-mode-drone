**更新时间**: 2025年12月11日  
**项目状态**: 核心功能已完成，SITL调试阶段

## 📋 项目概述

WuK (Wuhan University Kopter) 是一个基于ArduPilot的变构四旋翼无人机项目，实现了四旋翼在飞行模式和地面模式之间的动态切换。

### 核心特性

1. **三种工作模式**
   - **LOITER模式**: 标准四旋翼悬停，电机0°垂直朝下
   - **MORPH模式**: 0°→45°渐变过程，保持高度控制
   - **GROUND模式**: 90°水平构型，RC车式差速转向

2. **电机布局**
   - 标准X型布局：M1前右(45°), M2前左(-45°), M3后左(-135°), M4后右(135°)
   - 伺服驱动倾转：通过RC9通道控制0-90°倾转角度

3. **推力补偿机制**
   - Roll/Yaw因子旋转矩阵补偿（电机倾转后方向变化）
   - 垂直推力补偿：throttle /= cos(angle) 保持高度

4. **地面差速控制**
   - 俯仰杆(Pitch) → 前进/后退
   - 横滚杆(Roll) → 左右转向（差速推力）
   - 计算公式：left_thrust = forward - diff * 0.5,  right_thrust = forward + diff * 0.5

## 🎯 最新进展 (2025-12-11)

### 🚁 1. 飞控端变构逻辑优化 (Mode Morph)
*   **增加 45° 悬停缓冲期**：机臂变构成 45° 时，去除了旧版直接断开飞行控制切入 90° 并降为怠速的逻辑。新增了 `1000ms` 的悬停缓冲阶段 (`Morph_Hold45_ms`)，在这 1 秒内继续保持飞行姿态控制，结束后再平稳转入地面怠速和 90° 展开，防止突然掉高或姿态失控。
*   **指令发送降频与“关键角”护航**：
    *   取消了之前不论角度是否变化每帧都无脑入队发送的做法（这会导致队列瞬间塞满）。
    *   新增“关键角补推”机制（每变化 5° 视为一个关键角，额外重发 2 次），以低开销的方式大幅降低丢包导致的停滞感。
    *   驻留阶段（90°指令）改为每 `120ms` 周期发送一次，有效减轻底层发送队列（TX Buffer）压力。

### ⚙️ 2. Arduino 接收端控制提升 (arduino/src/main.cpp)
*   **重构舵机映射逻辑**：移除了代码中统一硬编码的 `map` 映射比例（如 `170->80`），改为对 4 路电机舵机进行单独独立的极性和范围定义（`MOTOR_SERVO_0 ~ 3_FLIGHT_DEG / GROUND_DEG`），以兼容各舵机物理安装及中心点的细微差异。
*   **引入断流预测与自动追赶闭环**：在跟随飞控 0-45° 实时报文时，加入了一套动态速度计算公式（预测续行）。如果串口短时丢包（< 1500ms），Arduino 会以预设安全速度继续演进并平滑追赶，避免机臂动作卡顿。
*   **地面模式切换指令“挂起”机制**：旧版中如果机臂未展至 90° 期间收到地面模式（`ACT1`高位）切换指令会被直接拒绝。现修改为将请求置于挂起状态 (`pendingGroundTransition`)，并在机臂到达指定位置后自动无缝切入地面模式。
*   **串口单次读取限流**：限制微控制器单个 `loop` 内最多只读取 96 字节报文，防止因累积了大量飞控串口数据而导致 Arduino 的主控循环被长时间阻塞。

### 📡 3. 底层通信与日志监控优化 (WuK_Comms)
*   **消除冗余串口日志防刷屏**：全面去除了底层每发送一帧都向地面站 `GCS_SEND_TEXT` 打印一次日志的做法。针对 `TX Buffer full`、心跳挤压、写入不完整等异常情况，增设了 `2000ms` 的冷却限制，彻底根除了之前因发日志而导致的通讯链路更拥堵的恶性循环。
*   **新增监控探针**：增加了吞吐量统计，每两秒向控制台定期输出队列深度和发送成功数（如 `[WuK-TX] sent=xxx(+xx) q=xx`），便于直观诊断通讯健康状况。继续使用 Autopilot我已经为你生成了基于提交 `1192d431c3` 到当前 `HEAD` 的完整更新日志。任务已完成。
